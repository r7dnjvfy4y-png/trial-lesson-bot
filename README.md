# Бот записи на пробный урок

Telegram-бот, который сам записывает учениц на бесплатный пробный урок —
без Calendly и без оплаты, всё происходит прямо в диалоге с ботом.

## Как это работает для ученицы

1. Пишет боту `/start` — сразу видит приветствие и три кнопки уровня:
   **A2 / B1 / B2**
2. Бот показывает свободные дату и время для этого уровня на ближайшую
   неделю, плюс кнопки «📅 Посмотреть запись на следующей неделе» и
   «🙈 Не нашли подходящее время»
3. Нажимает на дату/время — и сразу получает подтверждение с материалами.
   Отдельного шага «оставьте телефон» нет: контактом считается её
   Telegram (username и профиль), это видно вам в `/leads` и `/export`

Уроки проходят группами, до `CAPACITY_PER_SLOT` человек на один слот (по
умолчанию 6). Как только группа набралась, слот пропадает из списка, и
автоматически предлагается то же время на следующей неделе — специальной
настройки для этого не нужно, бот сам ищет ближайшую свободную дату в
пределах `DAYS_AHEAD` дней вперёд.

Если человек нажимает «Не нашли подходящее время» (или мест по расписанию
вообще не осталось) — бот предлагает записаться в лист ожидания одной
кнопкой.

Если ученица останавливается на шаге выбора даты дольше
`STALL_TIMEOUT_MINUTES` (по умолчанию 20 минут), бот сам мягко напомнит о
себе и уточнит причину кнопками: «Я передумала», «Не нашла время»,
«Согласовываю с родителями».

Обо всех действиях (новая запись, лист ожидания, «зависла» на шаге) бот
присылает вам уведомление в личные сообщения — это основной способ
следить за процессом в реальном времени. Подробнее — в разделе 7.

## Уровни и расписание

Три кнопки уровня показываются ученице, но по времени они делятся на две
группы — сейчас A2 и B1 занимаются вместе, у B2 отдельные слоты:

| День | Время | Кто занимается |
|---|---|---|
| Суббота | 14:30 | A2, B1 |
| Суббота | 15:30 | B2 |
| Суббота | 16:30 | B2 |
| Воскресенье | 10:00 | A2, B1 |
| Воскресенье | 11:00 | B2 |

Это настроено в `config.py` (`DISPLAY_LEVELS`, `LEVEL_TO_GROUP`,
`WEEKLY_SCHEDULE`) — см. раздел 6, если нужно поменять дни/время/уровни
или дать каждому уровню отдельное расписание.

## Тексты бота — редактируются вами прямо в Telegram, без кода

Все сообщения, которые бот отправляет ученицам (приветствие, подтверждение
записи, лист ожидания и т.д.), можно посмотреть и переписать прямо в
Telegram — командой **`/texts`** (работает только с вашего аккаунта,
`ADMIN_CHAT_ID`):

1. Отправьте боту `/texts` — придёт список всех редактируемых сообщений
2. Нажмите на нужное — бот покажет текущий текст
3. Пришлите новый текст обычным сообщением — он сразу заменит старый

**Жирный текст, курсив и т.д.** — да, форматируется прямо в Telegram: когда
пишете новый текст, выделите нужный фрагмент и нажмите на панели
форматирования (**Ж**, *К* и т.д., как в обычной переписке) — бот сохранит
форматирование как есть, ничего вручную вписывать не нужно.

Если текст содержит `{when}` и похожие фигурные скобки — это место, куда
бот сам подставляет дату/время, при редактировании их нужно просто оставить
как есть в тексте (бот подскажет, если такие переменные есть). Кнопка
«♻️ Сбросить на стандартный текст» под каждым сообщением возвращает
исходный вариант, если что-то захотите отменить.

Полный список редактируемых сообщений — в `texts.py`, там же лежат тексты
по умолчанию (те, что сейчас установлены).

### А как переименовать самого бота?

Имя бота, его описание (текст-приглашение до нажатия Start) и аватарка —
это НЕ часть `/texts`, а настройки самого бота в Telegram, они меняются
через `@BotFather`, тоже без кода:

- `/setname` → выбрать бота → написать новое имя (например, «Запись на
  пробный урок»)
- `/setdescription` → текст, который человек видит до первого сообщения
- `/setabouttext` → текст в профиле бота
- `/setuserpic` → аватарка

## Файлы проекта

- `bot.py` — вся логика бота и обработчики, включая админ-команды
- `config.py` — уровни, расписание, вместимость группы и прочие настройки
- `texts.py` — тексты бота по умолчанию (переопределяются через `/texts`)
- `database.py` — работа с базой SQLite (ученицы, записи, лист ожидания,
  переопределённые тексты)
- `scheduling.py` — генерация свободных дат по расписанию из `config.py`
- `keyboards.py` — кнопки бота
- `requirements.txt` — зависимости
- `.env.example` — шаблон переменных окружения
- `Procfile` — команда запуска для Railway

## 1 · Настройка окружения

1. Скопируйте `.env.example` в `.env`
2. Заполните переменные — подробности в комментариях внутри
   `.env.example`. Ключевые:
   - `BOT_TOKEN` — токен бота (получите на следующем шаге)
   - `ADMIN_CHAT_ID` — ваш Telegram ID для уведомлений и админ-команд

   Уровни/расписание — в `config.py` (см. таблицу выше и раздел 6), а
   тексты сообщений — через `/texts` прямо в боте (см. выше).

## 2 · Регистрация бота через BotFather — это и есть «установка» в Telegram

Отдельного «инсталлятора» у ботов нет — учениц просто находят бота по
username в поиске Telegram и жмут `/start`. А сам бот появляется так:

1. Откройте Telegram, в поиске введите `@BotFather`
2. Отправьте `/newbot`
3. Укажите имя бота (его увидит ученица, например «Запись на пробный
   урок») — потом всегда можно поменять командой `/setname`
4. Укажите username — обязательно заканчивается на `bot`
   (например, `AnaTrialLesson_bot`)
5. BotFather пришлёт токен вида `123456:ABC-DEF...` — вставьте его в
   `BOT_TOKEN`
6. Токен никому не показывайте — он даёт полный доступ к управлению ботом

## 3 · Как узнать свой ADMIN_CHAT_ID

1. Напишите в Telegram боту `@userinfobot`
2. Он пришлёт ваш числовой Id — вставьте его в `ADMIN_CHAT_ID`

## 4 · Локальный запуск (проверить перед деплоем)

```bash
pip install -r requirements.txt
python bot.py
```

Если в консоли появилось «Бот запущен» — всё работает. Напишите боту
`/start` в Telegram и пройдите весь путь ученицы сами.

## 5 · Деплой на Railway (чтобы бот работал круглосуточно)

### 5.1 · Регистрация и создание проекта

1. Зайдите на railway.app и нажмите Login
2. Войдите через GitHub — код бота нужно предварительно загрузить в
   GitHub-репозиторий
3. На главном экране нажмите + New Project
4. Выберите Deploy from GitHub repo и укажите репозиторий с кодом бота

### 5.2 · Переменные окружения

1. Внутри проекта откройте вкладку Variables
2. Добавьте все переменные из вашего `.env` (BOT_TOKEN, ADMIN_CHAT_ID,
   TIMEZONE, CAPACITY_PER_SLOT, DAYS_AHEAD, MIN_NOTICE_HOURS,
   STALL_TIMEOUT_MINUTES, QUIZLET_LINK, DB_PATH)

### 5.3 · Хранилище для базы данных

Railway периодически пересоздаёт контейнер, поэтому файл SQLite может
слетать — нужно подключить постоянное хранилище (иначе будут теряться и
записи, и тексты, отредактированные через `/texts`):

1. В проекте нажмите + New → Volume
2. Укажите путь монтирования, например `/data`
3. В переменной `DB_PATH` укажите `/data/bot.db`

### 5.4 · Запуск

1. После добавления переменных Railway запускает деплой автоматически —
   во вкладке Deployments появится статус Building, затем Success
2. Если команда запуска не подхватилась из `Procfile` автоматически,
   задайте её вручную в Settings → Deploy → Custom Start Command:
   `python bot.py`
3. Проверьте логи во вкладке Logs — должно появиться «Бот запущен»
4. С этого момента бот работает круглосуточно, даже если вы закроете
   компьютер

Railway даёт бесплатный доступ на первые дни, дальше — платный тариф от
$5 в месяц. Если карты для оплаты в долларах нет — можно попросить ИИ
подобрать альтернативный хостинг с оплатой в рублях, код бота останется
без изменений.

## 6 · Настройка уровней и расписания (код, не переменные окружения)

Уровни и расписание — в `config.py`:

```python
DISPLAY_LEVELS = ["A2", "B1", "B2"]        # кнопки, которые видит ученица

LEVEL_TO_GROUP = {                          # какое расписание использовать
    "A2": "А2-Б1",
    "B1": "А2-Б1",
    "B2": "Б2",
}

WEEKLY_SCHEDULE = {
    5: [("14:30", "А2-Б1"), ("15:30", "Б2"), ("16:30", "Б2")],  # суббота
    6: [("10:00", "А2-Б1"), ("11:00", "Б2")],                   # воскресенье
}
```

Если захотите дать каждому уровню отдельное расписание (а не делить A2 и
B1) — добавьте третью группу, например:

```python
LEVEL_TO_GROUP = {"A2": "А2", "B1": "Б1", "B2": "Б2"}

WEEKLY_SCHEDULE = {
    5: [("13:00", "А2"), ("14:30", "Б1"), ("15:30", "Б2"), ("16:30", "Б2")],
    6: [("10:00", "А2"), ("11:00", "Б2")],
}
```

Остальные параметры расписания — через переменные окружения:

| Переменная | За что отвечает |
|---|---|
| `CAPACITY_PER_SLOT` | Максимум учениц в одной группе |
| `DAYS_AHEAD` | На сколько календарных дней вперёд искать подходящие даты |
| `MIN_NOTICE_HOURS` | За сколько часов до слота ещё можно записаться |
| `STALL_TIMEOUT_MINUTES` | Через сколько минут молчания бот напомнит о себе |

## 7 · Где смотреть записи и контакты

Отдельной админ-панели нет — всё видно прямо в Telegram, двумя способами:

**В реальном времени.** Как только ученица что-то делает — записалась,
встала в лист ожидания, «зависла» на шаге и объяснила причину — бот сразу
присылает вам сообщение об этом в личку (по `ADMIN_CHAT_ID`).

**По запросу — админ-команды** (работают только с вашего аккаунта):

- `/leads` — список последних заявок: имя, уровень, статус (выбирает дату
  / записана / в листе ожидания и т.д.), контакт (Telegram-username) —
  весь процесс воронки на виду
- `/slots` — заполненность ближайших слотов по каждой группе расписания,
  например «Сб, 15 авг 15:30 (Б2) — 4/6»
- `/today` — список записей на сегодня
- `/export` — выгружает все заявки и контакты в CSV прямо в чат, можно
  открыть в Excel или Google Таблицах

Все данные хранятся в базе SQLite на сервере (см. раздел 5.3 про
постоянное хранилище) — не теряются между перезапусками.

## Чек-лист по порядку

1. Зарегистрировать бота через @BotFather и получить токен
2. Узнать свой ADMIN_CHAT_ID через @userinfobot
3. Заполнить `.env` по образцу `.env.example`
4. При желании — поправить уровни/расписание в `config.py`
5. Запустить бота локально и пройти весь путь ученицы самостоятельно
6. Загрузить код в GitHub-репозиторий
7. Задеплоить на Railway, добавить переменные окружения
8. Подключить Volume для базы данных
9. Через `/texts` проверить и, если нужно, переписать тексты под себя
10. Через `@BotFather` задать имя/описание/аватарку бота
11. Проверить логи и протестировать бота в проде от начала до конца

## Важно знать

- Оплаты в этом боте нет — пробный урок бесплатный. Если позже
  понадобится принимать оплату за дальнейшие занятия — попросите
  ИИ-ассистента добавить такой шаг в `bot.py`.
- Контакт ученицы — это её Telegram (username, если есть, иначе
  внутренний id). Отдельно телефон бот не запрашивает — вы сами пишете
  ученице в Telegram в течение дня, как и описано в тексте подтверждения.
- Хранение состояния диалога (FSM) — в памяти процесса. Если Railway
  перезапустит контейнер прямо во время выбора даты, ученице нужно будет
  заново нажать `/start` — сами записи, лист ожидания и отредактированные
  тексты при этом не теряются, они лежат в базе данных на подключённом
  Volume.
